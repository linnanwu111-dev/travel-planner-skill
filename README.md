# 旅行规划 Skill（内测）

面向国内旅行的 Agent Skill：支持已有计划、尚未确定目的地、提供攻略链接三类入口，整理每日行程、住宿餐饮、预算、天气与出发清单，生成可交互的 C 版旅行网页。

## 安装与体验

下载 [Skill 安装包](dist/travel-planner-current.zip)，交给支持本地 Skill 的 Agent 安装；Skill 目录为 `travel-planner/`，入口为 [SKILL.md](travel-planner/SKILL.md)。

也可以把仓库地址交给 Agent，并明确要求只安装本仓库的 `travel-planner/`，先阅读 SKILL.md。

示例：用这个旅行 Skill 帮我安排国庆去长沙的三天行程，两个人，预算合计4000元，别太赶。先问清楚我的需求，再查资料。

## 使用前需要知道

- 托管高德/FlyAI查询首次自动领取体验凭证，无需找维护者逐个申请或配置上游Key。凭证在本机私有保存，有效7天、查询时自动续领；每个安装每天80次规划查询，同一网络合计240次，全站有限额。遇到限额停止，不通过删除配置或更换标识绕过。详见[连接指南](travel-planner/references/hosted-service.md)。凭证不要发到公开Issue。
- 小红书、点评需要时使用用户授权的浏览器会话。遇登录/访问限制应停下让用户协助；不保证每个平台随时可读。
- 地点图片优先公开网页搜索；价格、天气和路线必须按实际返回标注，未知不是零元。示例JSON是合成演示，不是已核验攻略。
- 当前高德地图支持按钮缩放、拖动松手更新，不是完整动态地图；地图签名有效至返程后90天结束，届时需刷新。
- 手机发布优先当前Agent的正式托管能力，也可由Agent接力引导CloudBase。清单和费用调整保存在当前浏览器，不自动跨设备同步。

## 发布范围

本仓库只包含最终C版Skill及安装包，不包含私人旅行资料、服务端实现、SSH密钥、上游API密钥或浏览器登录态。第三方组件许可和作者说明见[THIRD_PARTY_NOTICES.md](travel-planner/THIRD_PARTY_NOTICES.md)。

当前为内测版本，不承诺所有Agent、手机或平台均完成端到端验收。问题反馈请附复现步骤，先遮盖行程隐私、订单和凭证。
