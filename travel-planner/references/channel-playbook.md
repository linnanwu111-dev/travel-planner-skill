# 各渠道职责与调用条件

首次调用前按 [环境准备与用户接力](channel-setup.md) 检查依赖、浏览器与授权；只提示缺失步骤，完成后恢复原查询。

| 渠道 | 主责 | 需要的输入 | 产出 | 不可替代的边界 |
|---|---|---|---|---|
| 小红书 | 用户收藏解读、少量关键实地体验与区域玩法 | 原帖/截图，或已选城市+区域+具体缺口 | 地点候选、原文事实与主观体验、体验适用时间 | 不作票价/开放/预约的唯一依据；热度不是适配度；搜索摘要不是读过全文 |
| 公开网页/图片搜索 | 城市封面与具体地点实景配图 | 已选城市、准确景点/分店名称 | 可用图片、原始来源、作者与许可依据 | 搜到不等于可转载，必须看图核对地点与使用条件 |
| 大众点评 | 具体餐厅分店与餐饮预算 | 当天餐区、饭点、人数、口味/禁忌、人均范围 | 店名地址、可见营业时间、人均、评价线索、主备选 | 人均不是承诺消费；酒店附近不是酒店内；缺少儿童/套餐条件不硬算 |
| 飞猪 FlyAI | 符合日期和条件的城际交通/住宿/景区门票候选与报价 | 出发到达城市、日期/时段、人数票种；入住退房、房数床型区域；景区、游玩日期、票种 | 准确车站/航站楼、车次时间、房型与价格条件、门票名称/价格适用日、预订跳转 | 不自动下单；搜索不是订单；登录浏览器不等于API Key；掩码/无票不是可买报价；门票平台售价不自动等于官方挂牌价 |
| 高德 MCP / API | POI消歧、名称补地址、真实通勤比较 | 城市+店名；核实后的起终点、交通偏好 | POI ID与GCJ02坐标、步行/公交/驾车的距离时间线路和可得费用 | 网页跳转链接不是路线查询；直线距离不是路线；驾车时间不是含等待的叫车时间 |
| 官方景区/运营方 | 营业、预约、票价、特殊停运/封闭 | 具体地点和游玩日期 | 适用条件、公告日期、预约窗口 | 社区经验不能覆盖新的官方限制 |
| 天气服务 | 对应游玩日期与地点的天气 | ISO日期、目的地坐标/时区 | 温度降水等、获取时间、覆盖日期 | 未来超窗口为未知；天气缓存与适用日期分开 |

## 按阶段安排查询

A已有计划：核实已订位置/时间 → 官方预约冲突 → FlyAI补未订交通住宿 → 公开资料补活动缺口，必要时小红书少量补查 → 点评餐厅 → 高德逐段 → 天气与预算复核。
B无玩法：交通可行性/预算量级 → 公开资料比较方向，必要时小红书少量体验补查 → 用户选方向 → FlyAI筛交通住宿 → 景点官方条件 → 点评 → 高德 → 天气。目的地已经明确则跳过城市比较。
C给链接：先读输入 → 提炼必留/可选 → 核官方冲突 → 对齐FlyAI窗口/住宿 → 点评落分店 → 高德。不是每个平台每次都必须使用。

读取规则：社区操作前执行research_gate，查询串行且按现有上限。搜不到/风险/普通登录/工具错误分别处理，不无限重试；达到上限就说明研究覆盖不足。查阅browser-research.md，具体工具使用先看实际帮助；本说明不授权发帖、收藏或读取个人订单历史。

## 把证据变成可用选择

每个推荐说明它如何满足用户约束，并附关键未知。通常餐厅每餐一个主选和一个有效备选，酒店比较2–3个足够；不是为了凑数量重复采集。备选应解决实际问题（排队、雨天、预算），不是任意额外地点。

冲突采用更具体且适用日期更新的依据：官方预约政策 > 旧社区经验；具体分店详情 > 搜索汇总。主观口味意见保留分歧，不平均成“事实”。无法裁定则留待确认，不改写成已核实。

## 图片单独处理

默认执行 [公开网页配图](place-images.md)，普通网页/图片搜索承担封面和地点素材。小红书不承担逐景点搜图或批量图片下载；用户提供笔记中的图可辅助理解偏好，但不能自动复制进分享页。

城市封面选有代表性的目的地全景或地标，适合横向裁切和柔化背景；地点图必须匹配具体地点，餐厅酒店不能错分店。按钮看原图；背景裁切不改变原图。没有图时使用纯色卡，不用失败的外链占位冒充素材。生成/示意图明确分类。

最终分享数据保留可公开来源和必要署名；Cookie、Key、签名访问参数、订单号、证件和登录截图不进入输出。图片使用问题影响图片交付，不阻止已获授权的其他规划工作。

## 景区门票优先查询FlyAI

景点和游玩日期基本确定后，用FlyAI查门票候选与价格，纳入该景点活动费用；不必把所有价格查询都转交官网。`search-poi`用于景点与票种发现，`keyword-search`可带日期、成人/儿童、单门票等具体需求进一步搜索。命令参数先查帮助。

注意：当前本机CLI 1.0.16的search-poi没有游玩日期参数，返回ticketInfo.priceDate必须与行程比较；自然语言带日期也不保证结果按日期过滤。只有实际响应明确支持日期、票种、包含项目与价格时才能作为quote，否则reference/unknown。不能把起价、导览套餐、游船联票当普通门票，也不能把null认作免费。

官方渠道仍负责核验预约要求、开放/停运、免票优惠条件，以及平台未覆盖或有冲突的价格。平台报价与官方票价分别留来源，不强行合并。

## 小红书调用边界

主要保留三项：读取用户主动分享的收藏；少量补查会影响选择的体验（排队、步行强度、入口体验、游览顺序）；验证玩法是否适合同行人和节奏。近况须注明日期，个体体验不当普遍事实。只查明确问题，公开资料与既有材料足够就跳过并记录理由。不负责报价、权威预约规则、精确通勤或默认配图。
